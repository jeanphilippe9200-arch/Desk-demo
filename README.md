# Grok Bot desk demo

Static GitHub Pages demo of the iPhone desk UI.

This is **example data only**. It is not connected to a live desk, a database, or Telegram. There is no backend and no secrets in this repository. All coins and mints are obviously fake (`EXAMPLE`, `DEMOX`, `SAMPLE`). FOMO links follow the official referral format and always include `r=savipww`. Some example mints point at the signup URL.

Open the Pages site and look for the yellow **DEMO · example data** bar and the **PAPER** badge.
